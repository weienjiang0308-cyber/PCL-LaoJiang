- 新主页采用 Minecraft 方块世界配图、P1 徽标和游戏/模组/光影入口。启动器恢复 PCL 原版多尺寸图标，安装包在原图标右下角增加安装标记；原作者署名和第三方声明保留，中英文切换继续可用。
- 图标资源检查见 `reports/executable-icon-check.json`：从安装程序、工作区 EXE 入口和启动器核心实际提取图标后，与选定图稿逐像素核对；启动器 ICO 同时校验与原图标文件完全一致。
- 安装、安装文件哈希、同目录升级保留数据、安装后 EXE 启动、保护其他启动器目录、卸载保留游戏与私有配置，均由 `scripts/Test-Installer.ps1` 在中文及空格路径沙盒验收。结果见 `reports/installer-p1-acceptance.json`。
- 安装器可选写入当前用户的 Windows 已安装应用清单，也可由用户主动勾选桌面快捷方式；自动化测试不创建系统快捷方式或注册条目。

演示身份没有正版访问令牌，因此游戏日志中在线认证、Realms 或 profile key 的拒绝属于本次演示环境的已知限制；不能将演示世界成功视为微软账号登录验收。

## 实现边界

1. 沿用 PCL CE 的 WPF 界面、实例管理、加载器安装及资源管理，并加入独立身份和配置。
2. 游戏安装能力由本项目的显式配置控制，不与 UI 语言或 Windows 地区绑定。
3. Mojang 官方来源、组件维护方和 BMCLAPI 社区镜像分别显示。精确域名匹配映射避免错误改写认证地址。
4. 原版“仅原始来源”模式不会偷偷追加 BMCLAPI。Modrinth / CurseForge 不再自动使用未单独确认的模组 API 代理。
5. 账号、共享配置、缓存、日志、临时目录和默认游戏目录放在独立便携目录；通知使用独立应用标识。默认不改 Windows GPU 偏好，相关选项保留为用户主动设置。
6. 上游二进制更新端点已移除；独立在线更新服务尚未配置，开发阶段通过本项目重新构建更新。
7. 本项目专属凭证支持所有构建配置；没有配置时显示中英文说明。CurseForge 不可用不会破坏 Modrinth 搜索。
8. 中英文沿用语言资源框架；英式英语缺失键已补齐。其他继承语言有显式英文后备文本，不宣称已完成全部翻译。

## 复现入口

从工作区根目录运行 `scripts/Test-Core.ps1`；安装用 `scripts/Test-Launcher.ps1`。测试会写入选定的 `sandbox/<name>`，独立保存报告。

演示世界复现示例（已安装对应测试实例及项目 Java 后）：

    & .\scripts\Test-Launcher.ps1 -SandboxName fabric-mirror -DemoInstance 1.20.1-fabric-0.20.1 -ShaderFile ComplementaryReimagined_r5.2.2.zip -VerifyWorld

世界验证等待测试驱动或测试人员在该沙盒游戏窗口点击 Play Demo World。本次通过桌面工具实际点击，日志验证进入世界，再自动关闭测试进程。未依赖向 GLFW 窗口发送无效的后台鼠标消息来宣称成功。

程序包的固定文件清单和 SHA256 见 `reports/package-manifest.json`。修改文件与原参考文件的哈希对照见 `reports/source-changes.json`。启动器包和源码包不包含测试游戏、存档、账号或凭证。
