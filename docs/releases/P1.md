# PCL老蒋定制版 P1 / Development preview

Plain Craft Launcher (PCL) 老蒋定制版，独立第三方开发预览版；基于 PCL CE v2.15.1，参考提交 `1a7653127d578efdb2a9388999a3fdc67d9e49d5`。原作者：龙腾猫跃（[赞助](https://ifdian.net/a/LTCat)）；社区基础：[PCL Community](https://github.com/PCL-Community/PCL-CE)。

## 下载与使用

- `PCL-LaoJiang-P1-Setup.exe`：Windows x64 图形安装包，默认安装到 `D:\Games\PCL-LaoJiang`；对应本地的 `PCL老蒋定制版-P1-安装.exe`。
- `PCL-LaoJiang-P1-Portable.zip`：解压后双击 `PCL老蒋定制版.exe`。
- `PCL-LaoJiang-P1-Source.zip`：对应源码和项目脚本；不包含游戏、Java、模组包或用户数据。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

运行安装版和便携版无需 CMD、PowerShell 或单独安装 .NET 10。游戏、存档、账号与缓存位于各自的 `Data`；升级和卸载保留该目录。界面支持简体中文、English (US) 和 English (United Kingdom)。安装程序未进行代码签名。

## 功能与验证范围

P1 安装包在项目沙盒通过安装、升级后数据保留、EXE 入口启动、文件哈希校验、拒绝覆盖无关目录以及卸载后数据保留的验证。EXE 文件图标也已在 Windows 资源管理器中人工确认。

下载链路的已有验证发生在 P1 品牌调整前的开发构建：Mojang 官方源安装 Minecraft 1.20.1；BMCLAPI 社区镜像安装 Minecraft 1.20.1 + Fabric 0.20.1；通过 Modrinth 下载模组、光影和资源包；以演示模式进入世界，并确认 Iris 与光影加载。这些记录不等于对 P1 全部下载组合进行重新验收，也不代表其他游戏版本或加载器均可用。

微软正版登录和 CurseForge 尚未验收，需要本项目获准使用的 Microsoft Client ID 和 CurseForge API Key。请勿提交密码、令牌、本地凭证配置或其他启动器的密钥。开发版尚未配置独立在线更新服务。

## English release notes

Independent third-party development preview for Windows x64. Includes a graphical EXE installer, portable EXE entry, Minecraft-inspired home artwork, the original PCL launcher icon, and Chinese/English settings.

The P1 installer passed sandbox checks for installation, upgrade and uninstall data preservation, native EXE startup, payload hashes, and protection of unrelated existing folders. Its file icon was also checked in Windows Explorer.

Earlier development builds completed Minecraft 1.20.1 installation from Mojang, Minecraft 1.20.1 with Fabric 0.20.1 from BMCLAPI, Modrinth resource downloads, and an Iris/shader demo-world launch. These are recorded examples, not verification of every P1 download combination, game version, loader, or paid account. Microsoft sign-in and CurseForge remain unverified and require project-owned credentials. The installer is unsigned and there is no independent update service yet.
